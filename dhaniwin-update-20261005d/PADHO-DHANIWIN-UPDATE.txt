==============================================================================
KYA FIX HUA (is baar: admin panel ke 2 asli backend bugs)
==============================================================================

Purane build me kuch SQL queries me **SQLite aur MySQL dono ki syntax ek hi
query me likhi hui thi**. Aisi query na MySQL par chalti hai, na SQLite par —
dono par error deti hai. Ye 2 jagah mili:

1) ADMIN DASHBOARD (admin -> Dashboard, panel ka pehla page)
   Query thi:
     WHERE created_at >= DATE('now','start of day') OR created_at >= CURDATE()
   MySQL isme DATE('now','start of day') par error deta hai, SQLite CURDATE()
   par. Matlab dashboard ke saare tiles (users, aaj ke recharge, aaj ka
   withdraw, pending recharge, profit) error me ja rahe the aur 0/khali
   dikh rahe the.
   FIX: ab driver dekh kar query banti hai —
     MySQL  -> created_at >= CURDATE() AND created_at < DATE_ADD(CURDATE(), INTERVAL 1 DAY)
     SQLite -> date(created_at) = date('now')
   Dashboard ab asli numbers dikhata hai (users total/aaj, wallet total,
   recharge total/aaj/pending, withdraw total/aaj, aaj ka profit).

2) AGENT PANEL -> aaj ki commission (Agents tab -> kisi agent ko inspect karo)
   Wahi galti: today's commission wali query me bhi DATE('now') + CURDATE()
   dono the, isliye "aaj ki commission" error de rahi thi.
   FIX: driver ke hisaab se same "today" condition. Ab total commission aur
   aaj ki commission dono sahi aati hain.

In dono fix me **game / bet / period / wager / result** ka koi code nahi chhua
gaya — sirf admin ke report numbers theek kiye gaye hain.
