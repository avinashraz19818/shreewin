HISTORY ME 1 NUMBER PICHE DIKHNA - YE BUG NAHI HAI
--------------------------------------------------

Screenshot me: upar header = ...334 (timer chal raha), history ka top row =
...333 (result 8). Yeh bilkul SAHI hai:

- header = jo period ABHI chal raha hai (isliye uska result history me nahi,
  timer khatam hone se pehle result kabhi list me nahi aata),
- history = jo periods KHATAM ho chuke hain; newest complete period hamesha
  running period se 1 piche hoga (334 chal raha hai -> 333 khatam ho chuka).

Check ka simple rule: "header ka number = history ke top ka number + 1"
(yani running period = last completed + 1). Aapke screenshot me 334 = 333 + 1,
sahi hai.

Purana bug iska ULTA tha: header ...791 dikha raha tha (ek puraana period)
jabki history me ...792 aa chuka tha -> matlab display khud piche tha aur bet
aage chali jati thi. Wahi cheez (client JS + server dono me -1 shift) hat gayi
hai, isliye ab display seedha current period dikhata hai.
