KYA PROBLEM THI (measurement se prove)
--------------------------------------
Ek hi waqt par:

  maanwin16.com (upstream)              -> 52618
  aapki site /lottery-draw/...json      -> 52618   <-- SHIFT NAHI (raw)
  aapki site /webapi/kv/issue/...       -> 52616   <-- SHIFT -1

Isliye:
  period  <- /webapi/kv/issue/*   -> 52616   (1 piche)
  result  <- /lottery-draw/*.json -> 52617+  (raw)
  => RESULT PERIOD SE 1 AAGE DIKHTA THA.

Frontend (index.html ke rewriteLotteryDraw) .json requests ko
/lottery-draw/... par modta hai -> wohi shift ka asar jagah hai.


IS v2 ME KYA HAI
----------------
  period_shift.php         -> shift helper (AR_PERIOD_SHIFT = -1)
  lottery_draw_proxy.php   -> /lottery-draw/* period+result, draw source + SHIFT
  lottery_issue_proxy.php  -> /{Lottery}/*.json, draw source + SHIFT
  webapi_proxy.php         -> /webapi/kv/issue/* , DRAW source pehle
                              (fail ho to maanwin16.com fallback) + SHIFT
  .htaccess                -> /{Lottery}/*.json routes

  AB PERIOD AUR RESULT DONO EK HI SOURCE SE AUR DONO 1 PICHE.

=====================================================================
  SETTING
=====================================================================
period_shift.php  mein:

    define('AR_PERIOD_SHIFT', -1);

    -1  -> period + result dono 1 piche   (DEFAULT)
     0  -> shift band (rollback)
    -2  -> 2 piche

Bas ek number. File delete karne ki zarurat nahi.


=====================================================================
  ROLLBACK
=====================================================================
AR_PERIOD_SHIFT ko 0 kar do  ->  shift band, baaki sab jaise tha
